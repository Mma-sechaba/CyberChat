# CyberChat - Cybersecurity Awareness Chatbot

## Overview
CyberChat is a cybersecurity awareness chatbot developed in C# using WPF. 
The chatbot helps users learn about online safety, password protection, phishing scams, malware, privacy, and Wi-Fi security.

The application uses GUI interaction, dynamic responses, memory recall, sentiment detection, delegates, and object-oriented programming principles.

---

## Features

- GUI-based chatbot interface
- Cybersecurity awareness tips
- Keyword recognition
- Random chatbot responses
- Conversation flow support
- Sentiment detection
- Memory recall
